Switching roles is a demo shortcut, not a sign-in.

Demo prototype. Role switching and HR authorization are simulated. All records are synthetic and are stored only in this browser, so they are not shared across users or devices.

This browser is blocking local storage, so records will be lost when the page reloads.

What is working, simulated, or deferred?

Working

  • One shared set of records carried Employer HR → Administrator → Student → Faculty with the same IDs
  • Required-field checks, status changes, duplicate-application prevention
  • Records survive role changes and page reloads in this browser

Simulated

  • Role switching (no login)
  • HR authorization checkbox
  • The single student (Alex Lee, STU-001) and faculty reviewer

Deferred

  • Real authentication and role permissions
  • Shared central storage
  • Eligibility verification
  • Review decisions, return for revision, placement decisions
